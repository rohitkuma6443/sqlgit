# SQL - CASE Statement

MySQL | Beginner to Advanced | Dataset, Solved Examples, Exercises, Practice Questions and Interview Questions

## 1. What is CASE in SQL?

The `CASE` expression is used to apply conditions and return different results depending on which condition is satisfied.

In simple language, CASE works like IF–ELSE in programming.

For example, we want to classify employees according to their salary:

- Salary of ₹60,000 or more → High Salary
- Salary of ₹40,000 or more → Medium Salary
- Otherwise → Low Salary

```
SELECT
    employee_name,
    salary,
    CASE
        WHEN salary >= 60000 THEN 'High Salary'
        WHEN salary >= 40000 THEN 'Medium Salary'
        ELSE 'Low Salary'
    END AS salary_category
FROM employees;
```

The `CASE` expression checks the conditions from top to bottom. When a condition matches, it returns that result and stops checking further conditions.

## 2. CASE Syntax

```
SELECT
    column_name,
    CASE
        WHEN condition1 THEN result1
        WHEN condition2 THEN result2
        WHEN condition3 THEN result3
        ELSE default_result
    END AS new_column
FROM table_name;
```

| Keyword | Meaning                                         |
| ------- | ----------------------------------------------- |
| `CASE`  | Starts the conditional expression               |
| `WHEN`  | Specifies a condition                           |
| `THEN`  | Specifies the result when the condition is true |
| `ELSE`  | Specifies the default result                    |
| `END`   | Ends the CASE expression                        |
| `AS`    | Gives the result column an alias                |

`ELSE` is optional. If no condition matches and `ELSE` is omitted, SQL returns `NULL`.

## 4. Solved Examples — Basic CASE

### Example 1: Classify employees by salary

Question: Display each employee's salary category.

```
SELECT
    employee_name,
    salary,
    CASE
        WHEN salary >= 60000 THEN 'High'
        WHEN salary >= 40000 THEN 'Medium'
        ELSE 'Low'
    END AS salary_category
FROM employees;
```

Sample output:

| employee_name | salary | salary_category |
| ------------- | ------ | --------------- |
| Rohit         | 50000  | Medium          |
| Amit          | 35000  | Low             |
| Priya         | 60000  | High            |
| Neha          | 40000  | Medium          |
| Vikas         | 70000  | High            |

Explanation: The conditions are checked in order. Since Rohit earns ₹50,000, he matches the second condition and is classified as Medium.

### Example 2: Classify employees by city

```
SELECT
    employee_name,
    city,
    CASE
        WHEN city = 'Mumbai' THEN 'Western Region'
        WHEN city = 'Pune' THEN 'Western Region'
        WHEN city = 'Delhi' THEN 'Northern Region'
        ELSE 'Other Region'
    END AS region
FROM employees;
```

### Example 3: Classify products by price

```
SELECT
    product_name,
    price,
    CASE
        WHEN price >= 50000 THEN 'Premium'
        WHEN price >= 15000 THEN 'Standard'
        ELSE 'Budget'
    END AS price_category
FROM products;
```

### Example 4: Identify expensive and affordable products

```
SELECT
    product_name,
    price,
    CASE
        WHEN price > 20000 THEN 'Expensive'
        ELSE 'Affordable'
    END AS price_status

```

## 5. CASE with Multiple Conditions

You can combine conditions using `AND` and `OR`.

### Example 5: Classify employees by salary and department

```
SELECT
    employee_name,
    department,
    salary,
    CASE
        WHEN department = 'IT' AND salary >= 60000
            THEN 'Senior IT Salary'
        WHEN department = 'IT'
            THEN 'Other IT Salary'
        WHEN salary >= 50000
            THEN 'High Salary - Other Department'
        ELSE 'Regular Salary'
    END AS employee_category
FROM employees;
```

Important: Put the most specific conditions first. A general condition placed earlier may match before a more specific condition is reached.

### Example 6: Classify orders by sales value

```
SELECT
    order_id,
    sales,
    CASE
        WHEN sales >= 50000 THEN 'Very High'
        WHEN sales >= 30000 THEN 'High'
        WHEN sales >= 10000 THEN 'Medium'
        ELSE 'Low'
    END AS sales_category
FROM orders;
```

## 6. CASE with Aggregate Functions

This is particularly useful for reporting and data analytics.

### Example 7: Count employees in each salary category

```
SELECT
    SUM(
        CASE WHEN salary >= 60000 THEN 1 ELSE 0 END
    ) AS high_salary_count,

    SUM(
        CASE WHEN salary >= 40000 AND salary < 60000
             THEN 1 ELSE 0 END
    ) AS medium_salary_count,

    SUM(
        CASE WHEN salary < 40000 THEN 1 ELSE 0 END
    ) AS low_salary_count
FROM employees;
```

This produces one row containing the number of employees in each category.

### Example 8: Count employees department-wise by salary category

```
SELECT
    department,
    SUM(CASE WHEN salary >= 60000 THEN 1 ELSE 0 END)
        AS high_salary_count,
    SUM(CASE WHEN salary < 60000 THEN 1 ELSE 0 END)
        AS other_salary_count
FROM employees
GROUP BY department;
```

### Example 9: Calculate total sales for high-value orders

```
SELECT
    SUM(
        CASE
            WHEN sales >= 30000 THEN sales
            ELSE 0
        END
    ) AS high_value_sales
FROM orders;
```

### Example 10: Count orders by sales category

```
SELECT
    SUM(CASE WHEN sales >= 50000 THEN 1 ELSE 0 END)
        AS very_high_orders,
    SUM(CASE WHEN sales >= 30000 AND sales < 50000
             THEN 1 ELSE 0 END)
        AS high_orders,
    SUM(CASE WHEN sales < 30000 THEN 1 ELSE 0 END)
        AS other_orders
FROM orders;
```

## 7. CASE with GROUP BY and ORDER BY

### Example 11: Group employees into salary bands

```
SELECT
    CASE
        WHEN salary >= 60000 THEN 'High'
        WHEN salary >= 40000 THEN 'Medium'
        ELSE 'Low'
    END AS salary_category,
    COUNT(*) AS total_employees
FROM employees
GROUP BY
    CASE
        WHEN salary >= 60000 THEN 'High'
        WHEN salary >= 40000 THEN 'Medium'
        ELSE 'Low'
    END;
```

This groups employees into salary categories and counts the employees in each category.

### Example 12: Sort departments in a custom order

Suppose we want IT first, followed by Sales, HR, and Finance.

```
SELECT employee_name, department, salary
FROM employees
ORDER BY
    CASE department
        WHEN 'IT' THEN 1
        WHEN 'Sales' THEN 2
        WHEN 'HR' THEN 3
        WHEN 'Finance' THEN 4
        ELSE 5
    END,
    employee_name;
```

The numbers control the sorting order; they are not part of the output.

## 8. Simple CASE vs Searched CASE

There are two common forms of `CASE`.

### A. Searched CASE

Each `WHEN` contains a condition.

```
SELECT
    employee_name,
    salary,
    CASE
        WHEN salary >= 60000 THEN 'High'
        WHEN salary >= 40000 THEN 'Medium'
        ELSE 'Low'
    END AS salary_category
FROM employees;
```

### B. Simple CASE

A single expression is compared against different values.

```
SELECT
    employee_name,
    department,
    CASE department
        WHEN 'IT' THEN 'Technology'
        WHEN 'Sales' THEN 'Business'
        WHEN 'HR' THEN 'Human Resources'
        WHEN 'Finance' THEN 'Accounts'
        ELSE 'Other'
    END AS department_name
FROM employees;
```

| Searched CASE                                  | Simple CASE                         |
| ---------------------------------------------- | ----------------------------------- |
| Checks conditions                              | Compares one expression with values |
| Supports `>`, `<`, `AND`, and other conditions | Useful for exact-value matching     |
| Best for ranges and complex rules              | Best for mapping categories         |

## 11. SQL CASE Interview Questions with Answers

### Q1. What is CASE in SQL?

`CASE` is a conditional expression that returns a result based on the first matching condition.

### Q2. What is the difference between CASE and IF?

`CASE` is a standard SQL expression supported by MySQL and many other database systems. MySQL also provides `IF()` as a function, but its syntax and portability differ.

### Q3. Is ELSE compulsory in CASE?

No. If no condition matches and there is no `ELSE`, the expression returns `NULL`.

### Q4. Can we use multiple WHEN conditions?

Yes. You can specify multiple `WHEN ... THEN` branches.

### Q5. Can CASE be used with aggregate functions?

Yes. For example:

```
SELECT
    SUM(CASE WHEN salary >= 50000 THEN 1 ELSE 0 END)
        AS high_salary_employees
FROM employees;
```

### Q6. Can CASE be used in ORDER BY?

Yes. It can create custom sorting rules.

### Q7. What is the difference between simple CASE and searched CASE?

Simple CASE compares one expression against values. Searched CASE evaluates separate Boolean conditions.

### Q8. Can CASE return numbers and strings?

A CASE expression can return numbers, strings, dates, or other compatible values. Its result type depends on the branches and database type-conversion rules.

### Q9. Can CASE be nested?

Yes. A `CASE` expression can appear inside another `CASE`, though excessive nesting can make the query difficult to maintain.

### Q10. Is CASE a statement or an expression in a SELECT query?

In a `SELECT` query, `CASE` is an expression: it returns a value for each row. MySQL also has a separate `CASE` statement used in stored programs.
